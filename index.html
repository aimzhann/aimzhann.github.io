📺 KDE-tv-remote - Control Your Linux Desktop from Android

⬇️ Download KDE Remote from GitHub

KDE Remote is a custom Android smart remote for Linux desktops, KDE Bigscreen, and media PCs, built on KDE Connect. It turns your Android phone or tablet into a powerful remote control with a tactile claymorphism interface, a smooth trackpad, D-pad navigation, media and volume controls, clipboard sync, and handy A/C/V shortcuts. Enjoy auto-repeat inputs and switch between light and dark themes for comfortable use day or night.

🚀 Getting Started

Before you download KDE Remote, make sure you have the following ready:

  • An Android phone or tablet to use as the remote control.
  • A Linux desktop, KDE Bigscreen device, or media PC that you want to control.
  • Both devices connected to the same local network (Wi-Fi or Ethernet).
  • KDE Connect installed on your Linux desktop. KDE Remote is built on KDE Connect, so this is required for pairing and communication.

🖥️ Using KDE Remote with Windows

KDE Remote is designed to run on Android and control a Linux desktop. If you are a Windows user, you can still benefit from KDE Remote by using it to control a Linux machine on your network. Here is how to get started from a Windows PC:

  1. On your Linux desktop, install and open KDE Connect. Ensure it is discoverable on your local network.
  2. On your Android device, download and install KDE Remote from the GitHub link above.
  3. Connect both your Android device and your Linux desktop to the same Wi-Fi or Ethernet network.
  4. Open KDE Remote on your Android device and follow the pairing process to connect to your Linux desktop.
  5. Once paired, you can use your Android device as a remote control while sitting at your Windows PC, as long as your Linux desktop is on the same network.

This setup is ideal for media PCs, home theater systems, or any scenario where your Linux desktop is connected to a TV or projector and you want a convenient wireless remote.

⚙️ How to Use KDE Remote

After pairing, the main screen of KDE Remote presents a clean, claymorphism-inspired layout. The large trackpad area responds to your finger movements for cursor control. Below the trackpad, you will find the D-pad with directional buttons for menu navigation. Media control buttons are arranged for easy access to play, pause, and skip functions. Volume buttons let you adjust the audio level on your Linux desktop without reaching for a keyboard.

The A/C/V shortcuts provide one-tap access to select all, copy, and paste, streamlining text editing tasks. Make sure KDE Connect is available on the Linux desktop or media PC, and confirm that both the Android device and the Linux system are on the same local network. When the pairing is complete, test the trackpad by moving your finger across the surface, then test the D-pad, media buttons, and volume buttons. Try the A/C/V shortcuts in a text field, and test clipboard sync with a short piece of text.

  • Trackpad test: move the pointer across the desktop and click on a safe item such as a folder.
  • D-pad test: move through a menu or media interface with the directional buttons.
  • Media test: play and pause a short audio or video file to confirm the media controls.
  • Volume test: raise and lower the volume to check that the remote sends the right commands.
  • Clipboard test: copy a short line of text on Android and paste it on the Linux desktop.

🛠️ Practical Tips for Smooth Use

Keep the Android device and the Linux desktop or media PC on the same network during use. A stable local connection helps the trackpad feel responsive and keeps the media and volume controls reliable. If the pointer movement feels too fast or too slow, adjust your usage by making shorter or longer swipes on the trackpad. The D-pad is useful for menus and media centers where directional steps are more precise than pointer movement.

The auto-repeat inputs are helpful for long lists, large volume changes, and repeated navigation. Hold the direction or volume button and release it when you reach the point you want. Clipboard sync is best for short text snippets, links, and commands that you want to move between devices. The A/C/V shortcuts reduce the need to switch between the remote and a keyboard when you are editing text on the Linux desktop.

Use the light theme in bright rooms and the dark theme in dim rooms or during evening use. The claymorphism interface keeps buttons visually distinct, which helps when you are using the remote from a couch or across the room. KDE Remote keeps the main controls within reach so you can manage a Linux desktop or media PC with a phone or tablet instead of a full keyboard and mouse.
